# 💻 Lógica de Programação

Este repositório foi criado para armazenar e organizar todos os exercícios, trabalhos e projetos desenvolvidos durante a disciplina de **Lógica de Programação** do curso de Ciência da Computação.

O objetivo principal aqui é documentar o meu progresso no aprendizado dos fundamentos de programação, algoritmos e resolução de problemas estruturados.

---

## 📚 Tópicos Abordados

Durante o semestre, os seguintes conceitos estão sendo explorados e aplicados nos códigos deste repositório:

* **Fundamentos:** Variáveis, tipos de dados e operadores (matemáticos, lógicos e relacionais).
* **Estruturas de Controle:** Condicionais (`if`, `else`, `switch`).
* **Estruturas de Repetição:** Laços (`for`, `while`, `do-while`).
* **Estruturas de Dados Básicas:** Vetores (Arrays) e Matrizes.
* **Modularização:** Criação e uso de Funções/Métodos.

---

* **Linguagem Principal:** Python
* **Ambiente de Desenvolvimento (IDE):** VS Code
